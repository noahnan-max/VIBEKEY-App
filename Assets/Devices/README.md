# AU05 complete 3D artwork

`au05-3d.png` is the full transparent device render from the project-authored revision B Blender exterior model. It retains the metal enclosure, microphone vents, dial, three keycaps, key symbols and visible side details. It is not a simplified diagram or a manufacturer product photograph.

The rendered appearance is based on public hardware reference proportions, not calibrated engineering CAD. The App uses a static render; it does not load a live rotatable 3D scene. The 320 × 1000 canvas and control projections were read from the same scene and frame. See `provenance.json` and `au05-3d-projection.json` for hashes and the projected dial/key regions.

The render is included in the public App at `Contents/Resources/Devices/au05-3d.png`. The build requires it and the native UI probe fails if it cannot be loaded. Third-party trademarks identify the compatible hardware and are not licensed by this project's MIT license.
